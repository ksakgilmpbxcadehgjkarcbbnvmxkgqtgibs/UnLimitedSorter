# UnLimitedSorter

Консольная утилита для сортировки файлов вида `Число. Строка` объёмом до 200 ГБ
с ограниченным потреблением оперативной памяти.

Условие сортировки: сначала по строке, при равенстве строк — по числу.

## Как запустить

dotnet run --project UnlimitedSorter.Console

Программа ожидает файл `input.txt` в рабочей директории и создаёт
отсортированный `output.txt`. Временные файлы пишутся в папку `TempDir`
рядом с исполняемым файлом.

## Настройка параметров

Размеры батчей и лимит открытых файлов вынесены в параметры конструкторов
и не захардкожены — при необходимости их можно изменить под конкретную
машину (доступную память, лимиты ОС на открытые файловые дескрипторы),
не трогая логику:

```csharp
// batchSizeRow — сколько строк максимум копится в памяти перед сбросом на диск
// batchSizeBytesCap — подстраховка по объёму данных на случай нестандартно длинных строк
var batchCreator = new BatchCreatorManager(batchSizeRow: 500_000, batchSizeBytesCap: 500_000_000);

// maxOpenFiles — сколько батч-файлов сливаются одновременно на одном уровне merge
var mergeManager = new MergeManager(maxOpenFiles: 100);
```

Текущие значения по умолчанию подобраны как баланс между потреблением
памяти (~180-200 МБ пиковой памяти на батч) и количеством временных
файлов.
